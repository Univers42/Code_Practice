Write a function that merges two sorted lists into a single sorted list.

Given two lists of integers list1 and list2, both already sorted in ascending order, the function must return a single list with all the elements, also sorted in ascending order.

Rules:
- Both input lists are already sorted in ascending order.
- Duplicates must be kept in the result.
- An empty input list must be handled correctly.

The function must be declared as:

def shadow_merge(list1: list[int], list2: list[int]) -> list[int]:

Expected output examples:
Input: shadow_merge([1, 3, 5], [2, 4, 6]) -> [1, 2, 3, 4, 5, 6]
Input: shadow_merge([1, 2, 3], [4, 5, 6]) -> [1, 2, 3, 4, 5, 6]
Input: shadow_merge([1], [2, 3, 4]) -> [1, 2, 3, 4]
Input: shadow_merge([], [1, 2, 3]) -> [1, 2, 3]
Input: shadow_merge([1, 1, 2], [1, 3, 3]) -> [1, 1, 1, 2, 3, 3]
