Write a function that determines whether two strings are permutations of each other.

Given two strings s1 and s2, the function must determine whether one can be obtained by rearranging the characters of the other. The comparison is case-sensitive, and whitespace and punctuation count as regular characters.

Rules:
- The comparison is case-sensitive ('A' is different from 'a').
- Whitespace and punctuation count as regular characters.
- Two empty strings are permutations of each other (True).
- Strings of different length cannot be permutations.

The function must be declared as:

def string_permutation_checker(s1: str, s2: str) -> bool:

Expected output examples:
Input: string_permutation_checker("abc", "bca") -> True
Input: string_permutation_checker("abc", "def") -> False
Input: string_permutation_checker("listen", "silent") -> True
Input: string_permutation_checker("hello", "bello") -> False
Input: string_permutation_checker("", "") -> True
Input: string_permutation_checker("a", "") -> False
Input: string_permutation_checker("Abc", "abc") -> False
Input: string_permutation_checker("a gentleman", "elegant man") -> True
