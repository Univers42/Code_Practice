Exercise name: cryptic_sorter
Turn-in directory: rendu/cryptic_sorter
Files to turn in: cryptic_sorter.py
Allowed functions: None specified
Forbidden functions: sorted()

Write a function that sorts a list of strings according to several criteria.

Given a list of strings strings, the function must return a new list sorted according to the following criteria, applied in order.

Rules:
- Primary criterion: string length, shortest first.
- Secondary criterion (same length): ASCII order, but letters are compared case-insensitively.
- Tertiary criterion (same length and lexically equal): number of vowels, ascending.
- Strings that are still equal keep their original relative order from the input list.
- Empty strings and an empty list must be handled correctly.
- Special characters are not counted as vowels.

The function must be declared as:

def cryptic_sorter(strings: list[str]) -> list[str]:

Expected output examples:
Input: cryptic_sorter(["apple", "cat", "banana", "dog", "elephant"]) -> ['cat', 'dog', 'apple', 'banana', 'elephant']
Input: cryptic_sorter(["aaa", "bbb", "AAA", "BBB"]) -> ['aaa', 'AAA', 'bbb', 'BBB']
Input: cryptic_sorter(["hello", "world", "hi", "test"]) -> ['hi', 'test', 'hello', 'world']
Input: cryptic_sorter([]) -> []
Input: cryptic_sorter([""]) -> ['']
