Write a function that checks whether two strings are anagrams.

Given two strings s1 and s2, the function must determine whether both contain exactly the same letters with the same frequency, ignoring case and spaces.

Rules:
- Case is ignored ('A' is treated the same as 'a').
- Spaces are ignored.
- Two empty strings are considered anagrams (True).
- Strings with a different letter count cannot be anagrams.

The function must be declared as:

def anagram(s1: str, s2: str) -> bool:

Expected output examples:
Input: anagram("listen", "silent") -> True
Input: anagram("Triangle", "Integral") -> True
Input: anagram("Dormitory", "Dirty Room") -> True
Input: anagram("hello", "world") -> False
Input: anagram("", "") -> True
Input: anagram("abc", "abcc") -> False
