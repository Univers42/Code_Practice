Escribe una función que dibuje una cuadrícula 2D a partir de una lista de coordenadas.

Dada una lista de coordenadas fireflies, donde cada elemento es una tupla (fila, columna), y un tamaño de cuadrícula size, la función debe devolver una lista de cadenas que representen una cuadrícula cuadrada de tamaño size x size.

Reglas:
- Las posiciones indicadas en fireflies se representan con el carácter '*'.
- Las posiciones vacías se representan con el carácter '.'.
- La coordenada (0, 0) corresponde a la esquina superior izquierda.
- Las coordenadas fuera de los límites de la cuadrícula deben ignorarse.
- Las coordenadas duplicadas deben tratarse como una sola.

La función deberá ser declarada como:

def firefly_grid(fireflies: list[tuple[int, int]], size: int) -> list[str]:

Ejemplos de salida esperados:
Input: firefly_grid([(0, 0), (1, 1), (2, 2)], 3) -> ['*..', '.*.', '..*']
Input: firefly_grid([(1, 1), (0, 1), (2, 1), (1, 0), (1, 2)], 3) -> ['.*.', '***', '.*.']
Input: firefly_grid([], 2) -> ['..', '..']
Input: firefly_grid([(0, 0), (0, 0), (1, 1)], 2) -> ['*.', '.*']
Input: firefly_grid([(0, 0), (5, 5)], 3) -> ['*..', '...', '...']
Input: firefly_grid([(1, 0), (1, 1), (1, 2)], 3) -> ['...', '***', '...']
