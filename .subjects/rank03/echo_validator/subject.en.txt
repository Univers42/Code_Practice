Write a function that checks whether a string is a palindrome, ignoring spaces and case.

Given a string text, the function must determine whether it reads the same from left to right as from right to left once spaces are removed and case is ignored.

Rules:
- Spaces are ignored.
- Case is ignored ('A' is treated the same as 'a').
- Only spaces are removed; any other character counts.
- An empty string is not considered a palindrome (False).

The function must be declared as:

def echo_validator(text: str) -> bool:

Expected output examples:
Input: echo_validator("racecar") -> True
Input: echo_validator("A man a plan a canal Panama") -> True
Input: echo_validator("race a car") -> False
Input: echo_validator("Was it a car or a cat I saw") -> True
Input: echo_validator("hello") -> False
Input: echo_validator("Madam Im Adam") -> True
Input: echo_validator("") -> False
