Nombre del ejercicio: ribbon_cuts
Directorio de entrega: rendu/ribbon_cuts
Archivos a entregar: ribbon_cuts.py
Funciones autorizadas: No especificado
Funciones prohibidas: No especificado

Escribe una función que calcule el número mínimo de cortes necesarios para dividir una cadena en fragmentos palindrómicos.

Dada una cadena ribbon, la función debe devolver el número mínimo de cortes necesarios para que cada fragmento resultante sea un palíndromo, es decir, que se lea igual de izquierda a derecha que de derecha a izquierda.

Reglas:
- Debe devolverse el número de cortes realizados, no el número de fragmentos resultantes.
- Una cadena vacía requiere 0 cortes.
- Un único carácter siempre es un palíndromo.
- La comparación distingue mayúsculas de minúsculas ('A' es distinto de 'a').

La función deberá ser declarada como:

def ribbon_cuts(ribbon: str) -> int:

Ejemplos de salida esperados:
Input: ribbon_cuts("aab") -> 1
Input: ribbon_cuts("aba") -> 0
Input: ribbon_cuts("abcba") -> 0
Input: ribbon_cuts("abcd") -> 3
Input: ribbon_cuts("aabaa") -> 0
Input: ribbon_cuts("abac") -> 1
Input: ribbon_cuts("") -> 0
