Exercise name: ribbon_cuts
Turn-in directory: rendu/ribbon_cuts
Files to turn in: ribbon_cuts.py
Allowed functions: None specified
Forbidden functions: None specified

Write a function that calculates the minimum number of cuts needed to split a string into palindromic fragments.

Given a string ribbon, the function must return the minimum number of cuts needed so that every resulting fragment is a palindrome, meaning it reads the same from left to right as from right to left.

Rules:
- The number of cuts made must be returned, not the number of resulting fragments.
- An empty string requires 0 cuts.
- A single character is always a palindrome.
- The comparison is case-sensitive ('A' is different from 'a').

The function must be declared as:

def ribbon_cuts(ribbon: str) -> int:

Expected output examples:
Input: ribbon_cuts("aab") -> 1
Input: ribbon_cuts("aba") -> 0
Input: ribbon_cuts("abcba") -> 0
Input: ribbon_cuts("abcd") -> 3
Input: ribbon_cuts("aabaa") -> 0
Input: ribbon_cuts("abac") -> 1
Input: ribbon_cuts("") -> 0
