Nombre del ejercicio: ft_list_remove_if
Ficheros esperados: ft_list_remove_if.c
Funciones autorizadas: free
--------------------------------------------------------------------------------

Escribe una función llamada ft_list_remove_if que elimine de la lista
recibida cualquier elemento cuyo dato sea "igual" al dato de referencia.

Se declarará de la siguiente manera:

void ft_list_remove_if(t_list **begin_list, void *data_ref, int (*cmp)());

cmp recibe dos void* y devuelve 0 cuando ambos parámetros son iguales.

Debes usar el fichero ft_list.h, que contendrá:

$>cat ft_list.h
typedef struct      s_list
{
    struct s_list   *next;
    void            *data;
}                   t_list;
$>
