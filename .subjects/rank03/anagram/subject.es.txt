Nombre del ejercicio: anagram
Directorio de entrega: rendu/anagram
Archivos a entregar: anagram.py
Funciones autorizadas: No especificado
Funciones prohibidas: No especificado

Escribe una función que compruebe si dos cadenas son anagramas.

Dadas dos cadenas s1 y s2, la función debe determinar si ambas contienen exactamente las mismas letras con la misma frecuencia, ignorando mayúsculas/minúsculas y espacios.

Reglas:
- No se distingue entre mayúsculas y minúsculas ('A' se trata igual que 'a').
- Los espacios se ignoran.
- Dos cadenas vacías se consideran anagramas (True).
- Cadenas con distinta cantidad de letras no pueden ser anagramas.

La función deberá ser declarada como:

def anagram(s1: str, s2: str) -> bool:

Ejemplos de salida esperados:
Input: anagram("listen", "silent") -> True
Input: anagram("Triangle", "Integral") -> True
Input: anagram("Dormitory", "Dirty Room") -> True
Input: anagram("hello", "world") -> False
Input: anagram("", "") -> True
Input: anagram("abc", "abcc") -> False
