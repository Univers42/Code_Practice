Escribe una función que compruebe si los paréntesis y corchetes de una cadena son válidos.

Dada una cadena s, la función debe determinar si cada símbolo de apertura tiene su correspondiente símbolo de cierre en el orden correcto. Los símbolos a considerar son (), [] y {}. Cualquier otro carácter de la cadena debe ignorarse.

Reglas:
- Los tipos de símbolos a considerar son (), [] y {}.
- Cada símbolo de apertura debe cerrarse con uno del mismo tipo.
- Los símbolos deben cerrarse en el orden correcto.
- Los caracteres que no son paréntesis ni corchetes se ignoran.
- Una cadena vacía es válida (True).

La función deberá ser declarada como:

def bracket_validator(s: str) -> bool:

Ejemplos de salida esperados:
Input: bracket_validator("()") -> True
Input: bracket_validator("()[]{}") -> True
Input: bracket_validator("(]") -> False
Input: bracket_validator("([)]") -> False
Input: bracket_validator("{[]}") -> True
Input: bracket_validator("hello(world)") -> True
Input: bracket_validator("((())") -> False
Input: bracket_validator("") -> True
