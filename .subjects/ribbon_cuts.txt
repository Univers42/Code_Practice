Nombre del ejercicio: ribbon_cuts
Directorio de entrega: rendu/ribbon_cuts
Archivos a entregar: ribbon_cuts.py
Funciones autorizadas: No especificado
Funciones prohibidas: No especificado

Escribe una funcion que calcule el numero minimo de cortes necesarios para dividir una cadena en fragmentos palindromicos.

Dada una cadena ribbon, la funcion debe devolver el numero minimo de cortes necesarios para que cada fragmento resultante sea un palindromo, es decir, que se lea igual de izquierda a derecha que de derecha a izquierda.

Reglas:
- Debe devolverse el numero de cortes realizados, no el numero de fragmentos resultantes.
- Una cadena vacia requiere 0 cortes.
- Un unico caracter siempre es un palindromo.
- La comparacion distingue mayusculas de minusculas ('A' es distinto de 'a').

La funcion debera ser declarada como:

def ribbon_cuts(ribbon: str) -> int:

Ejemplos de salida esperados:
Input: ribbon_cuts("aab") -> 1
Input: ribbon_cuts("aba") -> 0
Input: ribbon_cuts("abcba") -> 0
Input: ribbon_cuts("abcd") -> 3
Input: ribbon_cuts("aabaa") -> 0
Input: ribbon_cuts("abac") -> 1
Input: ribbon_cuts("") -> 0
