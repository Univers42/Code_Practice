Write a function that rotates a list to the right by k positions.

Given a list of integers arr and an integer k, the function must return a new list rotated to the right by k positions, meaning the last k elements move to the front. If k is greater than the length of the list, it wraps around (k is taken modulo the length).

Rules:
- Rotating right by k moves the last k elements to the front.
- If k is greater than the list length, it wraps around (k modulo the length).
- A k of 0 leaves the list unchanged.
- An empty list must be handled correctly.

The function must be declared as:

def twist_sequence(arr: list[int], k: int) -> list[int]:

Expected output examples:
Input: twist_sequence([1, 2, 3, 4, 5], 2) -> [4, 5, 1, 2, 3]
Input: twist_sequence([1, 2, 3], 1) -> [3, 1, 2]
Input: twist_sequence([1, 2, 3, 4], 0) -> [1, 2, 3, 4]
Input: twist_sequence([1, 2, 3], 5) -> [2, 3, 1]
Input: twist_sequence([], 3) -> []
