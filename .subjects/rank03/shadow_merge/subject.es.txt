Nombre del ejercicio: shadow_merge
Directorio de entrega: rendu/shadow_merge
Archivos a entregar: shadow_merge.py
Funciones autorizadas: No especificado
Funciones prohibidas: No especificado

Escribe una función que fusione dos listas ordenadas en una sola lista ordenada.

Dadas dos listas de enteros list1 y list2, ambas ya ordenadas de forma ascendente, la función debe devolver una única lista con todos los elementos, también ordenada de forma ascendente.

Reglas:
- Ambas listas de entrada ya están ordenadas de forma ascendente.
- Los duplicados deben conservarse en el resultado.
- Debe tratarse correctamente una lista de entrada vacía.

La función deberá ser declarada como:

def shadow_merge(list1: list[int], list2: list[int]) -> list[int]:

Ejemplos de salida esperados:
Input: shadow_merge([1, 3, 5], [2, 4, 6]) -> [1, 2, 3, 4, 5, 6]
Input: shadow_merge([1, 2, 3], [4, 5, 6]) -> [1, 2, 3, 4, 5, 6]
Input: shadow_merge([1], [2, 3, 4]) -> [1, 2, 3, 4]
Input: shadow_merge([], [1, 2, 3]) -> [1, 2, 3]
Input: shadow_merge([1, 1, 2], [1, 3, 3]) -> [1, 1, 1, 2, 3, 3]
