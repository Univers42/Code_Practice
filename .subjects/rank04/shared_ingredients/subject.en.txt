Exercise name: shared_ingredients
Turn-in directory: rendu/shared_ingredients
Files to turn in: shared_ingredients.py
Allowed functions: None specified
Forbidden functions: None specified

Write a function that calculates the intersection of several lists of integers.

Given a list of lists recipes, the function must return, sorted in ascending order, the elements that appear in ALL of the lists contained in recipes.

Rules:
- The result must be sorted in ascending order.
- The result must not contain duplicate elements.
- If recipes is empty, or if any of the lists it contains is empty, the result is an empty list.

The function must be declared as:

def shared_ingredients(recipes: list[list[int]]) -> list[int]:

Expected output examples:
Input: shared_ingredients([[1, 2, 3], [2, 3, 4], [2, 3, 5]]) -> [2, 3]
Input: shared_ingredients([[1, 2, 3, 4], [2, 4, 6, 8], [4, 8, 12]]) -> [4]
Input: shared_ingredients([[1, 2, 3], [4, 5, 6]]) -> []
Input: shared_ingredients([[1, 1, 2, 3], [1, 2, 2, 3], [1, 2, 3, 3]]) -> [1, 2, 3]
Input: shared_ingredients([]) -> []
Input: shared_ingredients([[1, 2, 3], []]) -> []
Input: shared_ingredients([[5]]) -> [5]
