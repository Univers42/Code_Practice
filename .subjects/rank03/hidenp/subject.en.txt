Write a function that checks whether the string small is a subsequence of the string big.

Given two strings small and big, the function must determine whether all characters of small appear in big in the same order, though not necessarily consecutively. The comparison is case-sensitive.

Rules:
- The characters of small must appear in big in the same order.
- They do not need to be consecutive.
- The comparison is case-sensitive.
- An empty small is a subsequence of any string (True).

The function must be declared as:

def hidenp(small: str, big: str) -> bool:

Expected output examples:
Input: hidenp("abc", "a1b2c3") -> True
Input: hidenp("ace", "abcde") -> True
Input: hidenp("aec", "abcde") -> False
Input: hidenp("", "abc") -> True
Input: hidenp("abc", "ab") -> False
Input: hidenp("aaaa", "aaa") -> False
Input: hidenp("sing", "subsequence testing") -> True
