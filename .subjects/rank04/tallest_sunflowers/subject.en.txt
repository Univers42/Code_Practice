Exercise name: tallest_sunflowers
Turn-in directory: rendu/tallest_sunflowers
Files to turn in: tallest_sunflowers.py
Allowed functions: None specified
Forbidden functions: None specified

Write a function that calculates the maximum of a sliding window over a list of integers.

Given a list of integers heights and a window size k, the function must return a list with the maximum value of each window position, as it slides from left to right with a step of 1.

Rules:
- A list with one maximum value per window position must be returned.
- An empty list must be returned if heights is empty, if k <= 0, or if k is greater than the length of heights.

The function must be declared as:

def tallest_sunflowers(heights: list[int], k: int) -> list[int]:

Expected output examples:
Input: tallest_sunflowers([1, 3, -1, -3, 5, 3, 6, 7], 3) -> [3, 3, 5, 5, 6, 7]
Input: tallest_sunflowers([1, 2, 3, 4, 5], 2) -> [2, 3, 4, 5]
Input: tallest_sunflowers([5, 4, 3, 2, 1], 1) -> [5, 4, 3, 2, 1]
Input: tallest_sunflowers([1, 2, 3], 3) -> [3]
Input: tallest_sunflowers([1, 2, 3], 4) -> []
Input: tallest_sunflowers([], 2) -> []
Input: tallest_sunflowers([1, 2, 3], 0) -> []
