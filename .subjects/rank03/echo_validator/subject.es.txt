Escribe una función que compruebe si una cadena es un palíndromo, ignorando los espacios y las mayúsculas/minúsculas.

Dada una cadena text, la función debe determinar si se lee igual de izquierda a derecha que de derecha a izquierda una vez eliminados los espacios e ignorando mayúsculas/minúsculas.

Reglas:
- Los espacios se ignoran.
- No se distingue entre mayúsculas y minúsculas ('A' se trata igual que 'a').
- Solo se eliminan los espacios; cualquier otro carácter cuenta.
- Una cadena vacía no se considera palíndromo (False).

La función deberá ser declarada como:

def echo_validator(text: str) -> bool:

Ejemplos de salida esperados:
Input: echo_validator("racecar") -> True
Input: echo_validator("A man a plan a canal Panama") -> True
Input: echo_validator("race a car") -> False
Input: echo_validator("Was it a car or a cat I saw") -> True
Input: echo_validator("hello") -> False
Input: echo_validator("Madam Im Adam") -> True
Input: echo_validator("") -> False
